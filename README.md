# Cruce de Efectivo

Automatización para búsqueda y lectura de extractos PDF fiduciarios.

## Funcionalidades

- Selección automática de año.
- Selección automática de mes.
- Filtrado por criterio.
- Lectura masiva de PDFs.
- Extracción de cuenta.
- Extracción de Balance Final.
- Generación de Excel consolidado.

Versión 1.0 en desarrollo.
